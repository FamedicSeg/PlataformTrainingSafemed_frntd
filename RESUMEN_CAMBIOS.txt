                    SOLUCIÓN: ERROR AL ASIGNAR 194 USUARIOS
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA
────────────────────────────────────────────────────────────────────────────────
❌ Al asignar 194 personas a un curso → ERROR / TIMEOUT
✅ Al asignar 1-2 personas → Funciona correctamente

CAUSA
────────────────────────────────────────────────────────────────────────────────
El código lanzaba 194 solicitudes HTTP simultáneas sin control:

    ANTES (código problemático):
    ═══════════════════════════════════════════════════════════════════════════
    const promesas = selectedUsers.map(user => 
      fetch(`${API_URL}/api/inscripciones`, { ... })
    );
    const respuestas = await Promise.all(promesas); // ❌ 194 simultáneas!
    ═══════════════════════════════════════════════════════════════════════════

    Consecuencias:
    • Sobrecarga del servidor
    • Timeout de conexión
    • Límite de conexiones concurrentes excedido
    • Sin barra de progreso


SOLUCIÓN
────────────────────────────────────────────────────────────────────────────────
Procesar en lotes/batches de máximo 10 usuarios simultáneos:

    DESPUÉS (código optimizado):
    ═══════════════════════════════════════════════════════════════════════════
    const BATCH_SIZE = 10;
    for (let i = 0; i < totalUsers; i += BATCH_SIZE) {
      const batch = selectedUsers.slice(i, i + BATCH_SIZE);
      const promesas = batch.map(user => fetch(...));
      const respuestas = await Promise.all(promesas); // ✅ Solo 10 simultáneas
      // Actualizar barra de progreso
    }
    ═══════════════════════════════════════════════════════════════════════════

    Ventajas:
    ✅ Solo 10 solicitudes simultáneas (configurable)
    ✅ Barra de progreso en tiempo real
    ✅ Mejor manejo de errores
    ✅ Soporta 1000+ usuarios fácilmente
    ✅ No bloquea la interfaz

¿NECESITAS CAMBIAR EL TAMAÑO DE LOTE?
────────────────────────────────────────────────────────────────────────────────

Opciones:
  • 5:   Más lento pero más seguro

  • 15:  Más rápido pero más carga
